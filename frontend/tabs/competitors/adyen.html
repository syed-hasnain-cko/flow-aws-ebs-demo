Drop-in — Sessions flow

One /sessions call, then Adyen's prebuilt Drop-in renders the payment method list, 3DS and redirects.

Components — Card

You own the layout; Adyen renders only the secure card fields (Card component, Sessions flow).

Hosted Checkout

/sessions with mode: "hosted" returns a URL on Adyen's hosted page; the shopper returns to the shared success/failure pages with sessionResult. Requires a theme ID created in the Adyen Customer Area.

Advanced flow — /paymentMethods, /payments, /payments/details

You orchestrate three server calls yourself; the Web SDK (Drop-in) only collects and hands you state.data. Redirects are finalised on the result page via /payments/details.
